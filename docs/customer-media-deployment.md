# مدارک تصویری مشتری

این قابلیت فقط جدول جدید `customer_media` را اضافه می‌کند و ردیف‌ها یا ساختار جدول مشتریان و اطلاعات مالی قبلی را تغییر نمی‌دهد. مدارک اختیاری‌اند؛ ثبت و ویرایش قدیمی بدون فایل همچنان کار می‌کند. تا قبل از اجرای مهاجرت، ورودی مدارک غیرفعال است.

پس از دریافت کد و در فرایند معمول انتشار:

```sh
php artisan migrate --force
npm run build
php artisan route:cache
php artisan view:cache
```

پیش از اجرای migrate، فهرست مهاجرت‌های در انتظار نسخه بررسی شود. از `migrate:fresh` یا جایگزینی دیتابیس برای فعال‌سازی این قابلیت استفاده نشود. مهاجرت همین جدول روی محیط توسعهٔ محلی اجرا و ثابت‌ماندن تعداد و محدودهٔ شناسه‌های مشتریان، وام‌ها، اقساط و پرداخت‌های قبلی بررسی شده است؛ اجرای آن روی سرور مستلزم تأیید مسئول استقرار است.

فایل‌ها روی دیسک خصوصی `local` با پیشوند `private/customer-media` و نام تصادفی ذخیره می‌شوند؛ فقط مسیرهای احرازشده ادمین با مجوز مشاهده مشتری آن‌ها را ارائه می‌کنند. مسیر فیزیکی از تنظیم دیسک `local` تعیین می‌شود. پوشه `storage/app` باید بین انتشارها حفظ شود و وب‌سرور به آن دسترسی نوشتن داشته باشد؛ اجرای pull نیاز به حذف یا بازسازی این پوشه ندارد.

**پشتیبان داخلی فعلی سامانه فقط دیتابیس را پوشش می‌دهد.** برای بازیابی کامل مدارک، همراه بک‌آپ دیتابیس از فایل‌های دیسک خصوصی هم نسخه پشتیبان نگهداری شود.

حداکثر هر عکس ۵ مگابایت و ویدئو ۲۰ مگابایت است؛ PHP باید دست‌کم `upload_max_filesize=20M` و `post_max_size=40M` داشته باشد. تغییر خودکار در تنظیمات PHP یا سرور انجام نمی‌شود.

دوربین از مرورگر و دستگاه متصل استفاده می‌کند و به HTTPS (یا localhost) و اجازه دوربین نیاز دارد. ضبط بدون صداست و پس از ۳۰ ثانیه متوقف می‌شود؛ انتخاب ویدئوی آماده محدودیت حجم دارد. بستن پنجره، خروج از صفحه یا تعویض مشتری دسترسی دوربین را متوقف می‌کند. ویرایش یا حذف فایل فقط با ذخیره فرم اعمال می‌شود.

## فایل‌های قابلیت

- دیتابیس و مدل: `database/migrations/2026_11_04_150000_create_customer_media_table.php`، `app/Models/CustomerMedia.php`، رابطه در `app/Models/Customer.php`.
- ثبت، نگهداری و دسترسی: `app/Services/Customers/CustomerMediaService.php`، `app/Http/Controllers/Admin/CustomerMediaController.php`، اتصال به ثبت/ویرایش/حذف در `CustomerController.php`، مجوز مشاهده در `app/Services/Admin/AdminPermissionService.php`، مسیرها در `routes/admin.php`.
- رابط: `resources/views/admin/customers/index.blade.php`، `partials/media-editor.blade.php` و `partials/media-dialogs.blade.php` در همان پوشه، `resources/js/customer-media.js` و واردکردن آن در `resources/js/app.js`، `resources/css/customer-media.css`.
- تست: `tests/Feature/CustomerMediaTest.php`. آزمون‌ها با SQLite حافظه‌ای و فضای فایل آزمایشی اجرا شده‌اند. مرورگر Chrome با دوربین مجازی برای ثبت عکس، ضبط واقعی حدود ۳۰ ثانیه، لغو ضبط، انتخاب فایل در فرم multipart، نمایش ویدئو در تمام‌صفحه، تعویض مشتری، خطای مجوز دوربین و نمایش موبایل بررسی شده است؛ آزمایش روی دوربین فیزیکی انجام نشده است.
