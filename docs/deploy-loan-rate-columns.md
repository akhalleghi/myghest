# استقرار ستون‌های نرخ پرونده

این نسخه به دو ستون جدید در `customer_loan_files` نیاز دارد. دریافت کد با Git به‌تنهایی migration را اجرا نمی‌کند.

پس از بک‌آپ دیتابیس و توقف موقت درخواست‌های ثبت/ویرایش وام، در پوشه پروژه روی سرور اجرا شود:

```sh
php artisan migrate --path=database/migrations/2026_11_02_130000_add_daily_penalty_coefficients_to_customer_loan_files.php --path=database/migrations/2026_11_02_130100_snapshot_existing_loan_file_daily_coefficients.php --force
```

این فرمان فقط دو migration نام‌برده را اجرا می‌کند. مورد اول ستون‌های nullable را در صورت نبودن اضافه می‌کند؛ مورد دوم فقط نرخ‌های خالی را از نوع وام فعلی ثبت می‌کند و نرخ اختصاصی موجود را حفظ می‌کند. مبلغ، اقساط، رسیدها، روابط و شناسه‌های قبلی بازنویسی نمی‌شوند. نرخ تاریخیِ تغییرکرده‌ای که در بک‌آپ ذخیره نشده قابل بازیابی نیست؛ مبنای اولیه همان نرخ فعلی نوع وام است.

پس از اجرا، ثبت وام و نمایش نرخ‌ها بررسی شود. از اجرای `migrate:fresh`، `migrate:reset` یا rollback حذف‌کنندهٔ ستون‌ها استفاده نشود. در بازگشت به کد قبلی، ستون‌های افزوده‌شده حفظ شوند. `.env` و فایل‌های آپلودشدهٔ سرور جایگزین نشوند. سایر migrationهای معوق باید جداگانه بررسی شوند.
